# Claude System Template

Шаблон для розгортання AI-системи з двох вузлів: **стратег** (mac-mini) + **диспетчер** (vuzol).

## Архітектура

```
┌─────────────────────────────────────────────────────────┐
│                   Tailscale Mesh (VPN)                    │
│                                                          │
│  ┌──────────────────────┐    ┌─────────────────────────┐ │
│  │  🧠 mac-mini         │    │  🖥️ vuzol               │ │
│  │  macOS, M4, 16GB     │◄──►│  Ubuntu 24.04, 8GB      │ │
│  │                      │    │                         │ │
│  │  РОЛЬ: Стратег       │    │  РОЛЬ: Диспетчер        │ │
│  │  • Приймає рішення   │    │  • Зберігає пам'ять     │ │
│  │  • Запускає агентів  │    │  • Тримає чергу задач   │ │
│  │  • Керує workflow    │    │  • 24/7 online          │ │
│  │  • Звітує            │    │  • Обслуговує запити    │ │
│  └──────────────────────┘    └─────────────────────────┘ │
│           │                            │                 │
│           ▼                            ▼                 │
│    ~/spaces/                   Qdrant :6333              │
│    ~/.claude/rules/            PostgreSQL :5432          │
│    ~/claude-system/            Task API :8000            │
│                                Cloudflare Tunnel         │
└─────────────────────────────────────────────────────────┘
```

## Потоки даних

```
mac-mini ──heartbeat (15хв)──→ Task API (:8000)
mac-mini ──пам'ять──────────→ Qdrant (:6333)
mac-mini ──бекапи───────────→ vuzol (SSH)
vuzol    ──задачі───────────→ mac-mini (Task API pull)
```

## Вузли

| Вузол | Залізо | OS | Роль |
|-------|--------|----|------|
| **mac-mini** | M4, 16GB | macOS 15 | Стратег + Виконавець |
| **vuzol** | 8GB, 75GB SSD | Ubuntu 24.04 | Диспетчер 24/7 |

## Розгортання з нуля

## Ключові принципи

- **mac-mini приймає рішення.** vuzol лише виконує.
- **Пам'ять трирівнева:** файли → Qdrant (семантичний пошук) → PostgreSQL (ACID)
- **FREE FIRST:** Nemotron 🆓 → 429 → DS Flash → DS Pro → Opus 5 (лише критика)
- **Ніколи inline що можна делегувати.**
