## Вузли

| Вузол | Залізо | OS | Роль |
|-------|--------|----|------|
| **vuzol** | 8GB, 75GB SSD | Ubuntu 24.04 | Диспетчер 24/7 |
| **mac-mini** | M4, 16GB | macOS 15 | Стратег + Виконавець |

## Потоки даних

```
mac-mini ──heartbeat (15хв)──→ Task API (:8000)
mac-mini ──пам'ять──────────→ Qdrant (:6333)
mac-mini ──бекапи───────────→ vuzol (SSH)
vuzol    ──задачі───────────→ mac-mini (Task API pull)
```

## Структура репозиторію

| Папка | Що всередині |
|-------|-------------|
| `vuzol/` | Nginx, systemd, Docker, скрипти, конфіги, безпека |
| `memory/` | Трирівнева система пам'яті (Qdrant + PostgreSQL + файли) |

## Розгортання з нуля

1. **vuzol** → `vuzol/README.md`
2. **Пам'ять** → `memory/README.md`

## Ключові принципи

- **Пам'ять трирівнева:** файли → Qdrant (семантичний пошук) → PostgreSQL (ACID)
- **fail-soft:** Qdrant впав → PostgreSQL текстовий пошук → не краш
- **Heartbeat:** mac-mini відмічається кожні 15хв на Task API
- **НЕ роби LLM-виклики в hot path пам'яті**
