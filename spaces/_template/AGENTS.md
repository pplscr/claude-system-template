# AGENTS.md — Інваріанти для всіх агентів простору

## Базові правила

1. **SPACE.md перший** — завжди читай SPACE.md перед будь-якими діями
2. **Один простір = одна задача** — не змішуй контексти різних просторів
3. **Результат завжди** — кожен запуск агента має закінчуватись результатом або помилкою
4. **Не мовчи** — якщо щось незрозуміло, запитай, не вгадуй

## Пам'ять

- Факти зберігаються у файлах `.md` у `memory/` простору
- Синхронізація з Qdrant — автоматична (cron щогодини)
- Перед важливим рішенням — пошук у Qdrant

## Моделі

- Прості дії (читання, grep) → Nemotron 🆓
- Середні (написання коду) → DS Flash
- Складні (архітектура) → DS Pro
- Критика (code review) → Opus 5

## Помилки

- Логувати в `errors.log`
- Не повторювати одну й ту ж дію >3 разів
- Якщо застряг — ескалювати (створити задачу для mac-mini)
