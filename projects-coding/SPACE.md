# 🏠 SPACE.md — Ідентичність простору

## Назва
**projects-coding** — основний простір для розробки на mac-mini.

## Призначення
Цей простір — головне середовище для всіх проектів розробки. Тут зберігаються:
- Активні задачі
- Правила та стандарти кодингу
- Агенти-помічники (dev, review, test)
- Історія завершених задач

## Машина
- **mac-mini** — локальна розробка
- **OS**: macOS (Apple Silicon / Intel)

## Власник
- @ruslanmaneliuk

## Стек за замовчуванням
- Python 3.12+, JavaScript/TypeScript, Shell
- FastAPI, React, PostgreSQL
- Docker, GitHub Actions

## Правила простору
1. Один проект — одна тека в `workspace/`
2. Кожна задача має TASK.md
3. Перед push — обов'язкове рев'ю
4. Жодних секретів у репозиторії
