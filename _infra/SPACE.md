# _infra — Infrastructure

Server infrastructure configuration files for vuzol and mac-mini.

## Contents

| Directory | Purpose |
|-----------|---------|
| `config/` | Model routing, CLI configs, environment settings |
| `docker/` | Docker Compose files, container definitions |
| `nginx/` | Nginx reverse proxy configuration |
| `systemd/` | Systemd unit files for services |
| `scripts/` | Infrastructure automation scripts |
| `digest/` | Digest-based monitoring and alerts |
| `memory/` | Memory sync and Qdrant bridge configs |
| `projects/` | Project metadata and state files |
