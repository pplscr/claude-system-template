# 📊 Digest Pipeline — автономні звіти

Автономні дайджести, які збирають і агрегують дані без участі mac-mini.

## Компоненти

```
cron запускає:
  ├── 07:00  morning.py     — ранковий дайджест (погода, курс валют, розклад)
  ├── 12:00  midday.py      — денний дайджест (баланс, статус проектів)
  ├── 20:00  evening.py     — вечірній дайджест (підсумки дня, фінанси)
  └── Sun 10:00  weekly.py  — тижневий звіт (тренди, бюджет, аналітика)
```

## Що збирає кожен

### morning.py (07:00)
- Погода (OpenWeatherMap API)
- Курс валют (EUR/USD/UAH)
- Розклад на день (з state.py)
- Статус серверів

### midday.py (12:00)
- Баланс проектів
- Статус задач (pending/done)
- Heartbeat mac-mini
- Використання дисків

### evening.py (20:00)
- Підсумки завершених задач
- Фінансовий звіт за день
- Помилки за день
- Статус бекапів

### weekly.py (Неділя 10:00)
- Тижневі тренди
- Бюджет: витрати vs план (€50-80/€200)
- Топ агентів за використанням
- Рекомендації на наступний тиждень

## Дані

- PostgreSQL: `digest_archive` таблиця
- Формат: JSONB з type + date
- Зберігається історія за 90 днів

## Налаштування

```bash
# Запустити вручну
python3 /root/digest/morning.py
python3 /root/digest/evening.py --date 2026-07-30

# Подивитись архів
psql -U postgres -d orchestrator -c "SELECT type, date, data FROM digest_archive ORDER BY date DESC LIMIT 10;"
```
