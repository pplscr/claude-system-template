# 📊 Digest Pipeline — автономні звіти

Щоденні/щогодинні/щотижневі дайджести → Telegram.

## Розклад (cron)

```
0  7  * * *   morning.py     → Ранковий брифінг (07:00)
0 12  * * *   midday.py      → Денний статус  (12:00)
0 20  * * *   evening.py     → Вечірній звіт   (20:00)
0 10  * * 0   weekly.py      → Тижневий огляд  (неділя 10:00)
10 *  * * *   hourly-pipeline.sh → Щогодинний обхід
7  *  * * *   email-agent.py → Перевірка пошти (щогодини)
```

## Що збирає кожен дайджест

| Компонент | Джерело | Опис |
|-----------|---------|------|
| Погода | Open-Meteo API | Поточна + прогноз |
| Курс валют | Frankfurt API | EUR/UAH, EUR/CAD, USD/UAH |
| Баланс | OpenRouter API | Кредити на API ключах |
| Пошта | Gmail MCP | Непрочитані листи |
| Проекти | state.py | Статус + дедлайни |
| Фокус | AI-аналіз | Що важливо сьогодні |

## Архів

`archive/{type}-{YYYY-MM-DD}.json` — 90 днів історії.
Дельта-аналіз: порівняння з попереднім дайджестом (баланс, валюти, дедлайни).

## Додати новий компонент

1. Створити `collector-*.py` в папці digest
2. Додати виклик у відповідний дайджест (morning/midday/evening)
3. Дані → ключ у `data` словнику → автоархів
